import java.util.ArrayList;
import java.util.List;

/**
 * A series of digits from which every contiguous substring ("slice") of a
 * given length can be extracted, in the order in which they appear.
 */
class Series {

    private final String digits;

    /**
     * @param string the series of digits; must not be null or empty
     * @throws IllegalArgumentException if the series is null or empty
     */
    Series(String string) {
        if (string == null || string.isEmpty()) {
            throw new IllegalArgumentException("series cannot be empty");
        }
        this.digits = string;
    }

    /**
     * Returns all contiguous substrings of length {@code num}, in the order in
     * which they appear in the series (duplicates included).
     *
     * @param num the length of each slice
     * @return the slices in order of appearance
     * @throws IllegalArgumentException if {@code num} is zero or negative, or
     *                                  is greater than the series length
     */
    List<String> slices(int num) {
        if (num <= 0) {
            throw new IllegalArgumentException("Slice size is too small.");
        }
        if (num > digits.length()) {
            throw new IllegalArgumentException("Slice size is too big.");
        }

        int count = digits.length() - num + 1;
        List<String> result = new ArrayList<>(count);
        for (int start = 0; start < count; start++) {
            result.add(digits.substring(start, start + num));
        }
        return result;
    }
}

I implemented `Series.java` and kept the class and method names unchanged. I couldn't run the official tests, so I checked it with my own harness (19/19 passing), which can't confirm the exact error messages the real tests expect.

**What the code does:**
- **Constructor:** stores the digit string and rejects an empty or `null` input.
- **`slices(n)`:** returns every run of `n` adjacent digits, in order, including duplicates. For example, `"49142"` with `n = 3` gives `["491", "914", "142"]`.
- **Errors:** it throws `IllegalArgumentException` with these messages:
  - `"series cannot be empty"` for an empty input
  - `"Slice size is too small."` when `n` is 0 or less
  - `"Slice size is too big."` when `n` is longer than the string
- Very large or very negative values of `n` are rejected cleanly instead of overflowing.
