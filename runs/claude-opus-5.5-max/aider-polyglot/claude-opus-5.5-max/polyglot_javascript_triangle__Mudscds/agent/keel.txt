//
// Classifies a triangle as equilateral, isosceles, or scalene from the
// lengths of its three sides.
//
// Side lengths only form a triangle when there are exactly three of them,
// each is a finite number greater than zero, and they satisfy the triangle
// inequality: the sum of any two sides is greater than or equal to the third.
// Degenerate triangles (e.g. 1, 2, 3, where a + b === c) therefore count as
// triangles. Every classification is false for sides that don't form one.
//

const distinctLengths = (sides) => new Set(sides).size;

export class Triangle {
  constructor(...sides) {
    this.sides = sides;
  }

  get isValid() {
    if (this.sides.length !== 3) {
      return false;
    }

    // Number.isFinite rejects non-numbers, NaN, and +/-Infinity.
    const allPositive = this.sides.every(
      (side) => Number.isFinite(side) && side > 0,
    );
    if (!allPositive) {
      return false;
    }

    const [a, b, c] = this.sides;
    return a + b >= c && b + c >= a && a + c >= b;
  }

  // All three sides are the same length.
  get isEquilateral() {
    return this.isValid && distinctLengths(this.sides) === 1;
  }

  // At least two sides are the same length (so equilateral counts too).
  get isIsosceles() {
    return this.isValid && distinctLengths(this.sides) <= 2;
  }

  // All three sides have different lengths.
  get isScalene() {
    return this.isValid && distinctLengths(this.sides) === 3;
  }
}
EOF

`triangle.js` now implements the `Triangle` class. The skeleton's names are unchanged, and the folder holds only the original files. I couldn't run the project's own tests because Jest isn't installed, but a temporary 39-case test run passed.

**How it works**
- A shape counts as a triangle only if it has exactly three sides, each is a positive number, and any two sides add up to at least the third. Flat triangles such as `1, 2, 3` therefore count.
- For anything that isn't a triangle, all three properties return `false` instead of throwing an error.
- The type depends on how many different side lengths there are:
  - one length means equilateral;
  - two or fewer means isosceles, so equilateral triangles are isosceles too;
  - three means scalene.
- I added one extra public property, `isValid`, which the other three use.

**Testing:** There are no installed packages and I didn't add any. Instead I ran a temporary set of 39 cases with Node's built-in test runner, and all passed. It covered every case in the instructions, plus flat triangles, zero, negative, missing or extra sides, and non-numbers. I deleted those test files afterwards.

**Decision for you:** `(0.1, 0.7, 0.8)` is rejected, although on paper it is a flat triangle. JavaScript computes `0.1 + 0.7` as `0.7999999999999999`, which is just under `0.8`. Accepting it would need a small tolerance in the comparison, which departs from the stated `a + b ≥ c` rule, so I left the comparison exact. None of the cases in the instructions are affected.
