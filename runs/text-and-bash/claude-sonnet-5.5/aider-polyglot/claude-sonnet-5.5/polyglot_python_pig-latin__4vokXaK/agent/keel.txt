VOWELS = "aeiou"


def _translate_word(word):
    lower = word.lower()
    if not lower:
        return word
    if lower[0] in VOWELS or lower.startswith("xr") or lower.startswith("yt"):
        return word + "ay"

    i = 0
    while i < len(lower):
        if lower[i:i + 2] == "qu":
            i += 2
            break
        if lower[i] in VOWELS or (lower[i] == "y" and i > 0):
            break
        i += 1
    return word[i:] + word[:i] + "ay"


def translate(text):
    return " ".join(_translate_word(w) for w in text.split())

`translate` in `pig_latin.py` now handles all four rules, and my spot checks gave the expected output. I did not run a full test suite.

- **Rule 1:** words starting with a vowel, `xr` or `yt` get `ay` added.
- **Rule 2:** leading consonants move to the end, then `ay` is added.
- **Rule 3:** a `qu` after any leading consonants moves with them.
- **Rule 4:** a `y` after one or more consonants is treated as a vowel, so the consonants before it move.

Sentences are translated word by word, split on whitespace and rejoined with single spaces.
