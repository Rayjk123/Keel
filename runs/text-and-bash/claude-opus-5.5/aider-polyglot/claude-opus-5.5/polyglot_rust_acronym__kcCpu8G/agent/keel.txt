pub fn abbreviate(phrase: &str) -> String {
    phrase
        .split(|c: char| c.is_whitespace() || c == '-' || c == '_')
        .flat_map(|word| {
            let letters: Vec<char> = word.chars().filter(|c| c.is_alphabetic()).collect();
            let mut out = Vec::new();
            for (i, &c) in letters.iter().enumerate() {
                if i == 0 || (c.is_uppercase() && letters[i - 1].is_lowercase()) {
                    out.extend(c.to_uppercase());
                }
            }
            out
        })
        .collect()
}
EOF

I implemented `abbreviate` in `src/lib.rs`, and a temporary test with all the example phrases plus several edge cases passed (1 passed, 0 failed). I deleted that test file afterwards, so nothing remains in the project except the new function.

How it handles input:
- **Word breaks:** spaces, hyphens and underscores separate words, so "Liquid-crystal display" gives LCD and "The Road _Not_ Taken" gives TRNT.
- **Other punctuation:** removed, so "Thank George It's Friday!" gives TGIF and "Halley's Comet" gives HC.
- **Letters used:** each word gives its first letter, uppercased.
- **Mixed-case words:** a capital that follows a lowercase letter inside a word also counts, so "HyperText Markup Language" gives HTML.
- **All-capitals words:** these give only their first letter, so "GNU Image Manipulation Program" gives GIMP and "PHP: Hypertext Preprocessor" gives PHP.

`Cargo.toml` didn't need any changes, and no extra packages were used.
