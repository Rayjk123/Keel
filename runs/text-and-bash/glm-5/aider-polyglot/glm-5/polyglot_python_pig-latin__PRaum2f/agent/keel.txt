    for i in range(len(word)):
        if word[i] in vowels:

    # Fallback: no vowel found
    return word + 'ay'

## Summary

I implemented the `translate` function in `pig_latin.py` that converts English text to Pig Latin following all four rules:

1. **Rule 1**: Words starting with a vowel, "xr", or "yt" → add "ay" at the end
2. **Rule 2**: Words starting with consonants → move consonants to end, add "ay"
3. **Rule 3**: Words with consonants followed by "qu" → move consonants + "qu" to end, add "ay"
4. **Rule 4**: Words with consonants followed by "y" → move consonants before "y" to end, add "ay"

The implementation handles multi-word input by splitting on spaces and translating each word individually.
