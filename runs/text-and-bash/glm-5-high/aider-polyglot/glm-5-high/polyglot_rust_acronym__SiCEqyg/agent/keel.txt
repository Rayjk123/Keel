pub fn abbreviate(phrase: &str) -> String {
    // Replace hyphens with spaces to treat them as word separators
    phrase
        .replace('-', " ")
        .split_whitespace()
        .filter_map(|word| {
            word.chars()
                .find(|c| c.is_alphabetic())
                .map(|c| c.to_ascii_uppercase())
        })
        .collect()
}

All tests pass. The implementation correctly handles:

The solution:
- Replaces hyphens with spaces (treating them as word separators)
- Splits on whitespace to get individual words
- Finds the first alphabetic character in each word
- Converts it to uppercase and collects all letters into the acronym
