/// Converts a phrase into its acronym.
///
/// * Whitespace and hyphens separate words.
/// * All other punctuation (commas, apostrophes, underscores, ...) is dropped,
///   so `"Halley's"` is read as `"Halleys"`.
/// * The first letter of every word goes into the acronym.
/// * Inside a word, an upper-case letter directly after a lower-case one
///   (camelCase, e.g. `HyperText`) starts a new part and is included too.
///   Fully upper-case words such as `GNU` only contribute their first letter.
/// * The result is always upper-case.
pub fn abbreviate(phrase: &str) -> String {
    let mut acronym = String::new();

    // The previous character kept in the word being read, or `None` when the
    // next character starts a fresh word.
    let mut previous: Option<char> = None;

    for c in phrase.chars() {
        if c.is_whitespace() || c == '-' {
            // Word separator.
            previous = None;
        } else if c.is_alphanumeric() {
            let starts_part = match previous {
                None => true,
                Some(p) => p.is_lowercase() && c.is_uppercase(),
            };
            if starts_part {
                acronym.extend(c.to_uppercase());
            }
            previous = Some(c);
        }
        // Any other character is punctuation and is removed from the input
        // without affecting how the surrounding letters are interpreted.
    }

    acronym
}
EOF

- **Word splitting:** whitespace and hyphens separate words.
- **Punctuation:** everything else that isn't a letter or digit is dropped without splitting the word, so `"It's"` reads as `"Its"` and `"_Not_"` contributes `N`.
- **Letters taken:** each word contributes its first letter, uppercased. An uppercase letter that directly follows a lowercase one also counts, so `HyperText` gives `HT`. All-caps words like `GNU` contribute only `G`.
