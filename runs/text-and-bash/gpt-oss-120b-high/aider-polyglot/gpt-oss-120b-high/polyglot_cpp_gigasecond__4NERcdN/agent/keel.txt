Added implementations for gigasecond conversion:

**Changes Made**
- Defined a `Date` struct to represent date and optional time.
- Implemented `add_gigasecond` function that:
  - Accepts either a `Date` (date only) or a full `DateTime` (date + time) using `std::chrono`.
  - Converts the input into a `std::chrono::system_clock::time_point`.
  - Adds exactly 1,000,000,000 seconds (a gigasecond).
  - Returns the resulting `Date` (or `DateTime`) as a `std::chrono::system_clock::time_point`.

**Key Features**
- Uses `<chrono>` for precise time arithmetic.
- Handles leap years, month lengths, and time overflow automatically via `chrono`.
- Provides clean API within `gigasecond` namespace for easy integration with tests.
