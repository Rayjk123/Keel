/// Converts a phrase into its acronym, e.g. "Portable Network Graphics" -> "PNG".
///
/// Rules:
/// - Whitespace and hyphens separate words.
/// - All other punctuation (apostrophes, commas, underscores, ...) is ignored.
/// - Every word contributes its first letter.
/// - Within a word, an uppercase letter directly following a lowercase letter
///   also contributes ("HyperText" -> "HT"), whereas a word written entirely in
///   capitals contributes only its first letter ("GNU" -> "G").
///
/// The resulting acronym is always uppercase.
pub fn abbreviate(phrase: &str) -> String {
    let mut acronym = String::new();
    // The previous letter seen in the current word, or `None` at a word boundary.
    let mut previous: Option<char> = None;

    for c in phrase.chars() {
        if c.is_whitespace() || c == '-' {
            previous = None;
        } else if c.is_alphanumeric() {
            let starts_word = previous.is_none();
            let camel_case_hump = c.is_uppercase() && previous.is_some_and(char::is_lowercase);

            if starts_word || camel_case_hump {
                acronym.extend(c.to_uppercase());
            }
            previous = Some(c);
        }
        // Any other punctuation is simply skipped.
    }

    acronym
}
EOF

## Summary

**Implementation (`src/lib.rs`):** `abbreviate` builds the acronym in a single pass over the characters, remembering the previous letter in the current word:
- **Word separators:** whitespace and hyphens end the current word. Repeated separators like `"Something - I"` work fine.
