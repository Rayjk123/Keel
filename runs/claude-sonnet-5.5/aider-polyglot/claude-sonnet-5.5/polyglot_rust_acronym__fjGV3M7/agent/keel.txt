pub fn abbreviate(phrase: &str) -> String {
    let mut result = String::new();
    for word in phrase.split(|c: char| c.is_whitespace() || c == '-') {
        let mut prev_lower = false;
        let mut first = true;
        for c in word.chars() {
            if !(c.is_alphabetic() || c == '\'') {
                continue;
            }
            if c == '\'' {
                prev_lower = false;
                continue;
            }
            if first {
                result.extend(c.to_uppercase());
                first = false;
            } else if c.is_uppercase() && prev_lower {
                result.push(c);
            }
            prev_lower = c.is_lowercase();
        }
    }

`abbreviate` in `src/lib.rs` now turns a phrase into its acronym, and the unit tests I added pass. `Cargo.toml` needed no changes.

- **Separators:** whitespace and hyphens split words.
- **Punctuation:** other punctuation is dropped, so apostrophes and underscores never count as letters ("It's" → `I`, "_Not_" → `N`).
- **Letters taken:** each word contributes its first letter, uppercased. An uppercase letter that follows a lowercase one inside a word is also kept, so camelCase works ("HyperText" → `HT`).
- **All-caps words:** these count once ("PHP" → `P`, "GNU" → `G`).

The tests cover the three examples from the instructions plus extra cases like "GNU Image Manipulation Program" → `GIMP` and "Something - I made up from thin air" → `SIMUFTA`.
