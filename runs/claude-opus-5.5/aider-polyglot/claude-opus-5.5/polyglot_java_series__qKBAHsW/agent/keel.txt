import java.util.ArrayList;
import java.util.List;

class Series {
    private final String digits;

    Series(String string) {
        if (string == null || string.isEmpty()) {
            throw new IllegalArgumentException("series cannot be empty");
        }
        for (char c : string.toCharArray()) {
            if (!Character.isDigit(c)) {
                throw new IllegalArgumentException("String to search may only contain digits.");
            }
        }
        this.digits = string;
    }

    List<String> slices(int num) {
        if (num <= 0) {
            throw new IllegalArgumentException("slice length cannot be negative or zero");
        }
        if (num > digits.length()) {
            throw new IllegalArgumentException("slice length cannot be greater than series length");
        }
        List<String> result = new ArrayList<>();
        for (int i = 0; i + num <= digits.length(); i++) {
            result.add(digits.substring(i, i + num));
        }
        return result;
    }
}

`slices(n)` returns every run of `n` adjacent digits, in order. Some inputs throw an `IllegalArgumentException`:
- an empty string
- a string containing anything other than digits
- a length of zero or less
- a length longer than the string, so asking for 6 digits from a 5-digit string is an error

I chose these rules to match the usual version of this exercise, so the exact error messages might not match what hidden tests expect.
