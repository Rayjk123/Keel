VOWELS = set("aeiou")


def _translate_word(word):
    if not word:
        return word
    if word[0] in VOWELS or word.startswith("xr") or word.startswith("yt"):
        return word + "ay"
    i = 0
    while i < len(word):
        ch = word[i]
        if ch in VOWELS:
            break
        if ch == "q" and i + 1 < len(word) and word[i + 1] == "u":
            i += 2
            break
        if ch == "y" and i > 0:
            break
        i += 1
    return word[i:] + word[:i] + "ay"


def translate(text):
    return " ".join(_translate_word(w) for w in text.split())

I implemented `translate` in `pig_latin.py`. I ran it by hand on 15 sample inputs and every output matched the expected translation. There is no unit test file in the folder, so no test suite was run.

It works word by word, so phrases are handled too. For each word:
- **Rule 1:** If the word starts with a vowel, `xr` or `yt`, it just adds `ay` (`apple` → `appleay`, `xray` → `xrayay`).
- **Rule 2:** Otherwise it moves the leading consonants to the end and adds `ay` (`chair` → `airchay`).
- **Rule 3:** A `qu` is moved together with any consonants before it (`square` → `aresquay`, `quick` → `ickquay`).
- **Rule 4:** A `y` that comes after one or more consonants counts as a vowel (`rhythm` → `ythmrhay`, `my` → `ymay`). A `y` at the very start of a word stays a consonant (`yellow` → `ellowyay`).

Words are split on spaces and joined back with single spaces, so extra spacing in the input is not preserved.
