I've created the `Series.java` file with a `getSeries` method that:

- Extracts all contiguous substrings of length `n` from a string of digits
- Returns them in the order they appear
- Handles edge cases: returns empty list for null/empty inputs or non-positive `n`
- Returns just the full string when `n` exceeds the string length (the "deserve whatever you get" case)

The implementation was tested and verified with the example: `"49142"` produces `["491", "914", "142"]` for `n=3` and `["4914", "9142"]` for `n=4`.
