- **Valid triangle check:** a shape counts only if it has exactly three sides, each side is longer than 0, and any two sides add up to at least the third.
- **`isEquilateral`:** true for a valid triangle with all three sides equal.
- **`isIsosceles`:** true for a valid triangle with at least two equal sides, so equilateral triangles count too.
- **`isScalene`:** true for a valid triangle with all three sides different.
