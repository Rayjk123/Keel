VOWELS = set("aeiou")


def _translate_word(word):
    if not word:
        return word
    if word[0] in VOWELS or word.startswith(("xr", "yt")):
        return word + "ay"
    i = 0
    while i < len(word):
        ch = word[i]
        if ch in VOWELS:
            break
        if ch == "q" and i + 1 < len(word) and word[i + 1] == "u":
            i += 2
            break
        if ch == "y" and i > 0:
            break
        i += 1
    return word[i:] + word[:i] + "ay"


def translate(text):
    return " ".join(_translate_word(w) for w in text.split())

The task is finished: `translate` in `pig_latin.py` now converts English text to Pig Latin using the four rules.

- **Rule 1:** words starting with a vowel, `xr` or `yt` just get `ay` added.
- **Rules 2–4:** leading consonants move to the end up to the first vowel, then `ay` is added. A `qu` moves along with the consonants before it, and a `y` after at least one consonant counts as a vowel.
- Text is split into words, each word is translated, and the words are joined with single spaces.

Every example from the instructions gave the expected result when I ran it, and so did `yellow`, `queen` and a short phrase. There's no test file in the folder, so I couldn't run the official unit tests. It only handles plain lowercase words: capital letters and punctuation aren't treated specially, and repeated spaces become one space.
