The task is done. `sum-of-multiples.js` now exports a working `sum(factors, level)`. It collects every distinct multiple of each base value below the level and returns their total. Base values of 0 or less add nothing, which also keeps the loop from running forever on 0.

There were no tests in the folder, so I checked it by hand:
- `sum([3,5], 20)` gives 78, matching the example in the instructions.
- `sum([0], 1)` gives 0 and `sum([3,0], 4)` gives 3.
- `sum([2,3,5,7,11], 10000)` gives 39614537.
