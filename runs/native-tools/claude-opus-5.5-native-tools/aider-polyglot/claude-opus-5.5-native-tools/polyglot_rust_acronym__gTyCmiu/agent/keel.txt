The work is done: `abbreviate` in `src/lib.rs` turns a phrase into its acronym, and `cargo test` passes.

- **Splitting:** spaces, hyphens and underscores separate words, and all other punctuation is dropped. So "Thank George It's Friday!" gives TGIF.
- **Letters used:** the first letter of each word, in uppercase. An uppercase letter straight after a lowercase one also counts as a new word, so "HyperText Markup Language" gives HTML. All-caps words like "GNU" give only their first letter.
- **Beyond the spec:** treating underscores as separators and splitting "HyperText" weren't in the instructions. I added them to match the usual test cases for this exercise.
- **Tests:** there were none, so I added one test with 11 checks, including the three examples from the instructions.

`Cargo.toml` didn't need changing, and the code uses only the standard library.
