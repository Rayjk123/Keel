I implemented the Pig Latin translator in `pig_latin.py` with the following changes:

1. Added a `translate()` function that handles multi-word sentences by splitting, translating each word, and rejoining
2. Added a `translate_word()` function that implements the four Pig Latin rules:
   - Rule 1: Words starting with a vowel, "xr", or "yt" get "ay" appended
   - Rule 3: Words with consonant(s) followed by "qu" move the consonants and "qu" to the end, then add "ay"
   - Rule 4: Words with consonant(s) followed by "y" (not at the start) move the preceding consonants to the end and add "ay"
   - Rule 2: Words starting with one or more consonants move those consonants to the end and add "ay"
