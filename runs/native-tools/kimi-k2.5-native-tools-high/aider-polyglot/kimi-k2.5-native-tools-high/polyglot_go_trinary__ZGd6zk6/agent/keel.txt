I've implemented the `ParseTrinary` function in `trinary.go`. The function:

- Converts trinary number strings (containing only digits 0, 1, 2) to their decimal equivalent using first principles
- Uses an iterative approach: for each digit, multiplies the current result by 3 and adds the digit's value
- Returns `(0, false)` for invalid inputs (empty strings or strings containing characters other than 0, 1, 2)
- Returns `(decimal_value, true)` for valid trinary strings

For example:
- `"102012"` → `302` (as shown in the instructions)
- `"0"` → `0`
- `"3"` or `"12a"` → `0` with `ok=false`
