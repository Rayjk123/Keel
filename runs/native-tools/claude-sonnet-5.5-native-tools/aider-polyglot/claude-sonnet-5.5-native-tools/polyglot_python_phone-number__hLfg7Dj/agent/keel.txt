class PhoneNumber:
    def __init__(self, number):
        if any(c.isalpha() for c in number):
            raise ValueError("letters not permitted")
        if any(not (c.isdigit() or c in " ()-.+") for c in number):
            raise ValueError("punctuations not permitted")
        digits = "".join(c for c in number if c.isdigit())
        if len(digits) < 10:
            raise ValueError("must not be fewer than 10 digits")
        if len(digits) > 11:
            raise ValueError("must not be greater than 11 digits")
        if len(digits) == 11:
            if digits[0] != "1":
                raise ValueError("11 digits must start with 1")
            digits = digits[1:]
        if digits[0] == "0":
            raise ValueError("area code cannot start with zero")
        if digits[0] == "1":
            raise ValueError("area code cannot start with one")
        if digits[3] == "0":
            raise ValueError("exchange code cannot start with zero")
        if digits[3] == "1":
            raise ValueError("exchange code cannot start with one")
        self.number = digits
        self.area_code = digits[:3]
        self.exchange_code = digits[3:6]
        self.subscriber_number = digits[6:]

    def pretty(self):
        return f"({self.area_code})-{self.exchange_code}-{self.subscriber_number}"
EOF

`PhoneNumber` is implemented in `phone_number.py`. I ran only a quick check, not the exercise's unit tests, because none were in the directory. `PhoneNumber('+1 (613)-995-0253').number` gives `6139950253`. `PhoneNumber('1 613 995 0253').pretty()` gives `(613)-995-0253`.

- **Cleaning:** It strips spaces, `()`, `-`, `.` and `+`, and drops a leading `1` when there are 11 digits.
- **Errors:** It raises `ValueError` with the exact messages from the instructions. The checks cover letters, other punctuation, too few or too many digits, an 11-digit number that doesn't start with 1, and an area or exchange code starting with 0 or 1.
- **Extras:** I added `area_code`, `exchange_code` and `subscriber_number` attributes, plus a `pretty()` method that returns the `(NXX)-NXX-XXXX` form.

Letters are checked before other punctuation, so a number with both reports "letters not permitted".
