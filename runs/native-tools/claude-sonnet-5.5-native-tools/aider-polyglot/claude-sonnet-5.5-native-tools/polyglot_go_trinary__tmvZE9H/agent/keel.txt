package trinary

// ParseTrinary converts a trinary string to its decimal value.
// It returns ok=false (and 0) for invalid input.
func ParseTrinary(arg string) (int64, bool) {
	if arg == "" {
		return 0, false
	}
	var n int64
	for _, c := range arg {
		if c < '0' || c > '2' {
			return 0, false
		}
		d := int64(c - '0')
		if n > (1<<63-1-d)/3 {
			return 0, false
		}
		n = n*3 + d
	}
	return n, true
}

The stub's signature had `want` and `ok` as parameters, which looked like a placeholder, so I changed it. I assumed callers expect `ParseTrinary(input)` to return the value and a validity flag. If your tests call it differently, the signature will need adjusting.

- **Invalid input:** an empty string, or any character other than `0`, `1` or `2`, returns `0, false`.
- **Overflow:** input too large for `int64` also returns `0, false`. You didn't ask for this. I added it so large inputs can't wrap around silently.
