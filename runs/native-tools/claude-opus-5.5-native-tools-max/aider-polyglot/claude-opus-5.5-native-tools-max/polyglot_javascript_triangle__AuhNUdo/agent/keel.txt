The task is finished. I implemented the `Triangle` class in `triangle.js`, which is the only file I changed.

**How it works**
- The constructor keeps the original `...sides` signature and stores the sides.
- A shape only counts as a triangle if it has exactly three sides, each a finite number greater than 0, and the sides meet the triangle inequality with `≥`. So flat "triangles" like `(1, 1, 2)` are accepted, as the instructions allow.
- `isEquilateral`, `isIsosceles` and `isScalene` count how many different side lengths there are: 1, 2 or fewer, and 3. This means an equilateral triangle also counts as isosceles.
- If the sides don't form a triangle, all three return `false` instead of throwing an error.
- I added two helper getters, `isValid` and `distinctSideCount`. The existing names are unchanged.

**Testing**
- No test file came with the exercise, so I wrote the 21 standard cases for it plus 11 extra edge cases, and all 32 passed. The extras cover a zero side, negative numbers, NaN and Infinity, the wrong number of sides, non-number inputs and very large numbers.
- To check the tests could catch mistakes, I made five small deliberate bugs in copies of the code. The tests caught every one.
- The file passes ESLint's recommended rules.

**Notes**
- `npm test` won't run as is, because the Babel preset named in `babel.config.js` isn't installed. I didn't install anything. Instead I ran Jest with a temporary config using the Babel setup already on the machine, then deleted those scratch files.
- Side lengths are compared exactly, without rounding. For example, `0.1 + 0.2` and `0.3` count as different lengths, because they aren't exactly equal in JavaScript.
