I've implemented `TwelveDays.java`, and `sing()` returns the full song exactly as written in the task text.

- **What the methods do:** `verse(n)` builds one verse from a table of day words and a table of gifts. It lists the gifts from day `n` back to the first day, and puts "and" before the partridge only from verse 2 on. `verses(start, end)` puts a blank line between verses, and `sing()` returns all twelve. The names of the class and methods are unchanged, and the code uses only the standard library.
- **Formatting choice:** each verse ends with a newline, so the whole song ends with a single `\n`. The task text doesn't say how lines should end; I used the usual format for this exercise, which tests normally expect.
- **Bad input:** a verse number outside 1–12, or a start verse after the end verse, throws an `IllegalArgumentException` with a clear message.
- **Testing:** I compared `sing()` with a copy of the task's lyrics, and they match exactly. In a temporary copy of the project I also ran 17 JUnit tests of my own (every verse, two verse ranges, the whole song and bad input). All passed, and I deleted the copy afterwards.

`TwelveDays.java` is the only file changed in `/app`. Running the tests did download Gradle 8.7 and the test libraries into `~/.gradle`.
