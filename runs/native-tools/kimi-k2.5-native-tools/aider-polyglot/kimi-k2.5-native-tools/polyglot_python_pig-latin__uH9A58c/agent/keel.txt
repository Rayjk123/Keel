> read pig_latin.py
I have implemented the Pig Latin translator in `pig_latin.py`. The implementation handles all four rules:

1. **Rule 1**: Words starting with a vowel, "xr", or "yt" get "ay" appended
2. **Rule 2**: Words starting with consonants move the consonant cluster to the end and add "ay"
3. **Rule 3**: Words starting with consonants followed by "qu" move the consonants and "qu" to the end, then add "ay"
4. **Rule 4**: Words starting with consonants followed by "y" treat "y" as a vowel boundary, moving preceding consonants to the end and adding "ay"

The `translate` function processes multi-word sentences by splitting on whitespace, translating each word, and joining them back together. All test cases from the instructions pass correctly.
