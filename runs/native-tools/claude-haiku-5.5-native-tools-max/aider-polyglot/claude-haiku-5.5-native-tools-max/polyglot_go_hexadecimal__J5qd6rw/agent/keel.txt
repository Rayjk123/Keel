I rewrote `/app/hexadecimal.go` so `ParseHex` converts a hex string to decimal by hand, using only the language itself with no `strconv`, `math` or other conversion helpers. It builds, passes `go vet`, and is gofmt-clean.

**Signature change:** The stub had no return values, so it could not hand back a result. I kept the name `ParseHex` and the `out` and `errCase` names, and made them results:

```go
func ParseHex(in string) (out int64, errCase string)
```

**Behaviour:**
- Valid input returns the value and an empty `errCase`. Upper- and lower-case digits and leading zeros are accepted. For example, `10af8c` gives 1093516, `008000` gives 32768, and `008080` gives 32896.
- Invalid input returns `0` and `ErrCaseInvalid`. This covers the empty string, `0x` or `#` prefixes, signs, whitespace, and any non-hex character.
- Valid hex too large for `int64` returns `0` and `ErrCaseOverflow`, rather than silently wrapping.

Two choices were mine: the empty string counts as invalid, and overflow is reported as an error.

**Verification:** I tested from a scratch directory, `/tmp/hexcheck`, so the repo only contains the changed file. The checks covered the examples, the `int64` boundaries, every single-byte input, values 0 to 70000 in both cases, 200k random strings compared against `strconv`, random inputs with an invalid character inserted, and about 700k fuzz executions. All passed.

I left `.oracle/` untouched.
