from pig_latin import translate

# Comprehensive test suite
tests = [
    # Rule 1
    ('apple', 'appleay'),
    ('xray', 'xrayay'),
    ('yttria', 'yttriaay'),
    ('eat', 'eatay'),
    ('omelet', 'omeletay'),
    
    # Rule 2
    ('pig', 'igpay'),
    ('chair', 'airchay'),
    ('thrush', 'ushthray'),
    ('school', 'oolschay'),
    
    # Rule 3
    ('quick', 'ickquay'),
    ('square', 'aresquay'),
    
    # Rule 4
    ('my', 'ymay'),
    ('rhythm', 'ythmrhay'),
    
    # Multi-word
    ('apple pie', 'appleay iepay'),
    ('eat apple pie', 'eatay appleay iepay'),
]

all_passed = True
for inp, expected in tests:
    result = translate(inp)
    status = '✓' if result == expected else '✗'
    if result != expected:
        all_passed = False
    print(f\"{status} '{inp}' -> '{result}' (expected '{expected}')\")

print()
print('All tests passed!' if all_passed else 'Some tests failed!')
"

The task is complete. I implemented the `translate` function in `pig_latin.py` following all four Pig Latin rules:

1. **Rule 1**: Words starting with vowels, 'xr', or 'yt' → append 'ay'
2. **Rule 2**: Words starting with consonants → move consonants to end, append 'ay'
3. **Rule 3**: Words with consonants followed by 'qu' → move consonants and 'qu' to end, append 'ay'
4. **Rule 4**: Words with consonants followed by 'y' → move consonants before 'y' to end, append 'ay'

The implementation handles multi-word sentences correctly and all test cases pass.
