I implemented the `translate` function in `pig_latin.py` to convert English text to Pig Latin according to the four rules:

1. **Rule 1**: Words starting with a vowel, "xr", or "yt" get "ay" appended
2. **Rule 2**: Words starting with consonants move those consonants to the end, then add "ay"
3. **Rule 3**: Words with consonants followed by "qu" move the consonants AND "qu" to the end, then add "ay"
4. **Rule 4**: Words with consonants followed by "y" move only the consonants before "y" to the end, then add "ay"

The implementation handles multi-word input by splitting on whitespace, processing each word independently, and joining the results. All test cases pass correctly.
