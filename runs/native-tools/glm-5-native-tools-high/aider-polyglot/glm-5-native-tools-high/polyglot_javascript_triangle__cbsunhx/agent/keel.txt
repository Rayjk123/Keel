I've completed the implementation of the `Triangle` class in `triangle.js`. The class now correctly:

- **Validates triangles** in the constructor by checking that all sides are positive and satisfy the triangle inequality
- **`isEquilateral`** returns true only for valid triangles with all three equal sides
- **`isIsosceles`** returns true for valid triangles with at least two equal sides (includes equilateral)
- **`isScalene`** returns true only for valid triangles with three different length sides

All edge cases are handled including invalid triangles (zero/negative sides, triangle inequality violations), degenerate triangles (where sum equals third side - treated as valid per the spec), and floating-point values.
