`abbreviate` in `src/lib.rs` is implemented and the task is done. I didn't change `Cargo.toml`, because the code uses only the standard library.

**How it works**
- Whitespace and hyphens separate words. That includes the Unicode hyphens and dashes U+2010–U+2015.
- Other punctuation is dropped without splitting a word, so `It's` and `_Not_` stay whole.
- Each word contributes its first letter or digit, upper-cased.
- A capital right after a lowercase letter starts a new word, so `HyperText` gives `HT`. An all-caps word like `GNU` gives only `G`.
